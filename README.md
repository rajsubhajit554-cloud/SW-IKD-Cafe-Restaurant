# SW IKD Cafe & Restaurant Website

Official website repository for **IKD Cafe & Restaurant**.

## Files
- `index.html` - Main HTML webpage structure
- `styles.css` - Custom styling and design system
- `script.js` - Dynamic interactions, cart, filtering, and animations
- `assets/` - Image banners, logos, icons, and review photos
- `update-git.bat` - Automated Git update script

## How to Update Repository
Double-click `update-git.bat` or run `./update-git.bat` in the terminal to automatically stage, commit, and push changes to GitHub (`https://github.com/rajsubhajit554-cloud/SW-IKD-Cafe-Restaurant.git`).
